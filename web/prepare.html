Prepare upload file

Shrinks the survey export so it fits GitHub's 25 MB upload limit

Back to dashboard

The survey export carries an Answer Details sheet holding every individual question answer — tens of thousands of rows the dashboard never reads. It is almost the entire file size. This page drops the sheets you don't need and hands back a small workbook, typically under 1 MB instead of 45 MB. Everything happens inside your browser; the file is never uploaded anywhere.

  1. Export the responses from shwapno.app as usual.
  2. Drop the file above and press Prepare file.
  3. In GitHub open the data folder → Add file → Upload files → drop the prepared file → Commit.
  4. The dashboard rebuilds itself. The newest file wins, so old copies can stay.
