How to make it visible on every PC

  1. On the source PC, first let Visit Compliance and Audit Quality finish reading the PC raw-data folder and taking their snapshots.
  2. On this page click Download shared_snapshot.json.
  3. In the GitHub repository upload/replace that file at web/data/shared_snapshot.json and commit it. GitHub Pages will deploy it.
  4. After deployment, any PC/network opening the normal dashboard URLs will automatically show this shared snapshot. No raw-data folder is required on those viewer PCs.

Important: this publishes calculated dashboard data to the same public GitHub Pages site. The raw Excel and stock CSV files are not included, but the dashboard figures/details contained in the snapshot become viewable to people who can access the site.
